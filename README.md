# women-cloth-ecom-demo

A luxury contemporary women's apparel e-commerce storefront engineered with **Next.js 16.4.5**, **TypeScript**, **Tailwind CSS v4**, and **Local Storage** persistence.

## Features

- **Atelier Editorial Design**: High-fashion typography (`Playfair Display`, `Geist Sans`, `Alex Brush`), pastel pod arches, and responsive layout.
- **Persistent State (Local Storage)**:
  - Shopping Bag with item counter, size/color selectors, and quantity controls (`aurelia_cart_v1`).
  - Wishlist toggle and counter indicator (`aurelia_wishlist_v1`).
  - Promo code discounts (e.g. `SUMMER50` for 50% off, `AURELIA15` for 15% off).
  - VIP Newsletter Club subscription state.
- **Section Suite**:
  - Main Hero with 2-line title rule and 3-pillar trust guarantee shelf.
  - 5-pod Category showcase (Dresses, Tops & Tees, Jeans & Pants, Outerwear, Accessories).
  - Runway Season plum ribbon banner.
  - Featured Collection with interactive category filter tabs.
  - Brand Values & Botanical Perks.
  - Casual Looks Everyday split editorial banner.
  - Best Sellers collection with real ratings and quick actions.
  - 50% OFF Clearance promotional block.
  - Customer review stories.
  - VIP Newsletter and Style Community invitations.
  - Opulent Nocturne footer with store contacts and payment providers.
- **Modals & Drawers**:
  - Slide-over Cart Drawer with free shipping progress bar and checkout simulator.
  - Quick View garment inspection dialog.
  - Live Search modal with real-time matching.

## Getting Started

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) (or the next available port) to view the application.

## Production Build

```bash
pnpm build
pnpm start
```
